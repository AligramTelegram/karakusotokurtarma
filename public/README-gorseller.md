# Eklenecek görseller

Bu klasöre aşağıdaki dosyaları koyun (siteyi yayına almadan önce):

- `hero.jpg` — Ana sayfa hero arka planı (yazısız, temiz çekici fotoğrafı). Önerilen: 1920×1080, yatay, sağda çekici solda koyu alan.
- `og-image.jpg` — Sosyal medya paylaşım görseli. 1200×630.
- `logo.png` — Marka logosu (turuncu kartal + KARAKUŞ YOL YARDIM). Eklenince `components/Logo.tsx` içindeki SVG bununla değiştirilir.
- `favicon.ico` / `icon.png` — Sekme ikonu.

Görsel eklenene kadar hero koyu arka planla (bg-ink-light) sorunsuz çalışır.
